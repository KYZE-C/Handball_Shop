# Handball Shop

Handball Shop is a software project focused on creating an online shopping experience for handball-related products. The project is organised into separate client, server and shared components, with a solution file for managing the application.

## Features

- **Client application** – Provides the user facing part of the application.
- **Server application** – Separates server side functionality from the client.
- **Shared components** – Code that can be used across different parts of the application.
- **Modular structure** – Keeps the project organised into distinct components to support low coupling and high cohesion.

## Project Structure

```text
Handball_Shop/
├── Client/                 # Client-side application
├── Server/                 # Server-side application
├── Shared/                 # Shared code and components
├── HandballShopChart.png   # Project architecture diagram
└── Handball_Shop_v4.sln    # Visual Studio solution
```

## Getting Started

### Prerequisites

- [Visual Studio](https://visualstudio.microsoft.com/) or a compatible .NET development environment.
- The .NET SDK version required by the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KYZE-C/Handball_Shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Handball_Shop
   ```

3. Open `Handball_Shop_v4.sln` in Visual Studio.

4. Restore the required NuGet packages.

5. Configure any required application settings or dependencies.

6. Build the solution and run the application using the appropriate startup project.

*Note: The exact .NET version, configuration requirements and startup instructions depend on the project files.*
